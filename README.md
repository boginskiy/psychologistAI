### Этапы и функции

Это будет REST API 

Функции:
1) Пользователь:
    - регистрация, авторизация, аутентификация, восстановление пароля
    - предусмотреть разные роли
    - инфа по тарифам, сделать бесплатный с каким то маломощным функционалом
    - оплата тарифов для оказания психологической помощи
    - необходимо хранить данные клиента, историю его общения с AI,



2) Клиентский путь:
    - клиент зашел на сайт, зарегистрировался, заполнил анкету (можно в зависимости от того какой тип поддержки он выбрал)
    - начало работы, легкий разговор, сбор дополнительной информации о клиенте.
    - диалог, контроль этики. Сохранение данных для последующих сессий.
    - понять ожидания клиента. 
    - перенаправление на специалиста
    - возможно полноценный сайт. AI агент будет как точка входа и предварительный консультант.
